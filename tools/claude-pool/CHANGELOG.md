# Changelog

## 0.5.0

- Publish as an experimental Certiv Labs utility under Apache-2.0.
- Add deterministic, license-complete ZIP and tar release artifacts.
- Document the unofficial Anthropic relationship and intended account scope.

## 0.4.0

- Add Claude Desktop local-session routing through its local-binary override.
- Keep Desktop sessions pinned to their assigned account.
- Balance new sessions with native usage and rate-limit telemetry.
- Add a stable per-user installer, guided multi-account setup, and uninstaller.
- Preserve tokens, configuration, and runtime state across upgrades.

## 0.2.1

- Add secure setup-token capture and macOS Keychain storage.
- Balance terminal sessions and resume on detected usage-window limits.
