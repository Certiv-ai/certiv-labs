# Support

Certiv Labs tools are currently in public preview and have no external support
commitment.

During the preview:

- use repository issues for reproducible bugs and documentation problems;
- use discussions or internal product channels for ideas and broad questions;
- use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Every supported release must declare its maturity and maintenance level in this
repository and, once live, on its page at `certiv.ai/tools/`.
